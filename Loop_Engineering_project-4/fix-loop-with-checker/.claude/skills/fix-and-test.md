# Fix and Test Skill

## Project Rules
- Yeh ek email validator project hai
- Sab fixes `src/` folder mein hone chahiye
- Har fix ke baad `npm test` chala kar confirm karo
- Kabhi bhi test file (`test/`) ko khud change mat karo — sirf `src/` fix karo
- Fix minimal hona chahiye — sirf jo bug hai wahi fix karo, extra refactor mat karo

## Definition of Done
`npm test` exit code 0 de, aur koi bhi test file edit na hui ho
